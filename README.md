## My Portfolio — Gian Jedric Galagar
# Overview

This repository contains my personal developer portfolio, created for Assessment Task 1 (AT1). It is a responsive single-page website showcasing my background, achievements, course activities, projects, and technical skills.

The portfolio uses a minimalist and professional dark-mode design and demonstrates my understanding of HTML5, CSS3, JavaScript, Flexbox, CSS Grid, and responsive web design.

# Design

The portfolio uses a minimalist, professional dark-mode design with a dark slate background and cyan/electric-blue accents.

The design was inspired by modern developer portfolios, particularly:

- Brittany Chiang
- Lee Robinson
- Pedro Duarte

These served as visual references while developing an original layout suited to my current skill level and the requirements of the course.

# Development

The website was developed using semantic HTML5, hand-written CSS, and vanilla JavaScript. Flexbox and CSS Grid are used for page layouts, while CSS media queries provide responsive behavior across desktop, tablet, and mobile screen sizes.

JavaScript is used to add interactive functionality to the portfolio while keeping the implementation lightweight and framework-free.

AI tools were used as learning and development aids for design brainstorming, troubleshooting, and understanding HTML, CSS, and JavaScript concepts. The code was reviewed and adapted to ensure that I understand how the website works.

# Running Locally

Clone this repository and open index.html in a web browser.

No build tools or frameworks are required.
